# 🕷️ Spider — Interactive Particle Animation

An interactive, spider-inspired generative animation created using HTML5 Canvas, CSS, and JavaScript. The animation features moving particle trails, web-like lines, and smooth pointer-following motion against a dark background.

Move your mouse across the screen to interact with the animation and explore its dynamic visual effects.

## ✨ Features

- 🕸️ **Dynamic Web Effects** — Procedurally generated lines create an irregular, web-like appearance.
- 🖱️ **Mouse Interaction** — Animated particle systems follow the user's pointer.
- ✨ **Particle Trails** — Hundreds of particles create flowing trails and changing patterns.
- ⚡ **Real-Time Animation** — Uses `requestAnimationFrame()` for continuous rendering.
- 🎨 **Minimalist Design** — A black background with white graphics creates a high-contrast visual effect.
- 📐 **Responsive Canvas** — The canvas adjusts to the browser window dimensions.
- 🧮 **Mathematical Animation** — Uses trigonometry, interpolation, and distance calculations to produce natural movement.
- 🌐 **No Backend Required** — Runs in a modern web browser.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `spider/dist/` folder.
3. Open `index.html` in Chrome, Edge, or another modern browser.
4. Move your mouse across the screen to interact with the animation.

No package installation or backend server is required.

## 🧠 How It Works

1. **Particle initialization:** JavaScript creates particle objects with randomized starting positions.
2. **Pointer tracking:** A pointer event updates the target position of the animated systems.
3. **Motion calculation:** Trigonometric functions generate smooth, oscillating movement.
4. **Trail generation:** Distance calculations and interpolation produce connecting lines and particle trails.
5. **Continuous rendering:** `requestAnimationFrame()` updates the animation while the canvas adapts to the viewport size.

## 🎯 Project Purpose

This project demonstrates how mathematical calculations and browser-based graphics can be combined to create interactive generative art. It explores canvas rendering, animation loops, pointer events, and procedural visual effects.
